### 🔗 Featured Project: LinkStack Pro

**LinkStack Pro** is a full-stack web application for saving web links, adding notes, and organizing links into collections.

Users can create an account, sign in with their email or username, save and manage links, organize them into collections, update their profile, upload an avatar, change their password, and choose a saved light or dark appearance preference.

#### Tech Stack

* ⚛️ React 19 + Vite
* 🎨 Tailwind CSS
* 🧭 React Router
* 🔄 Redux Toolkit
* 🟢 Node.js + Express 5
* 🍃 MongoDB + Mongoose
* 🔐 JWT Authentication
* 🍪 HTTP-only Cookies
* ☁️ Cloudinary
* 📁 Multer
* 🛡️ Helmet
* 🔗 Axios

#### Key Features

* ✅ User registration and sign-in
* ✅ Sign in using email or username
* ✅ JWT access and refresh token authentication
* ✅ HTTP-only, Secure, SameSite cookies
* ✅ Automatic authentication restoration
* ✅ Automatic access-token refresh after 401 responses
* ✅ Protected frontend and backend routes
* ✅ Create, edit, list, and delete links
* ✅ Organize links into collections
* ✅ Link search and collection filtering
* ✅ Collection deletion with associated-link cleanup
* ✅ Profile updates
* ✅ Username and full-name management
* ✅ Avatar upload and removal
* ✅ Password change flow
* ✅ Persistent light/dark appearance preference
* ✅ Responsive Tailwind CSS interface
* ✅ Cloudinary avatar storage
* ✅ Ownership checks for user resources
* ✅ Centralized API error handling
* ✅ MongoDB persistence with Mongoose

#### Architecture

```text
React
  ↓
Axios
  ↓
Express API
  ↓
Authentication Middleware
  ↓
Controllers
  ↓
Mongoose Models
  ↓
MongoDB
```

Avatar uploads additionally use:

```text
React
  ↓
Axios
  ↓
Express
  ↓
Multer
  ↓
Cloudinary
```
